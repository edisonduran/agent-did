Agent-DID A2A Extension

Extension URI https://agent-did.org/a2a/identity/v1, for the capabilities.extensions of an A2A 1.0 Agent Card.

An agent that lists this extension states its Agent-DID and the keys it signs with, and signs its HTTP requests with HTTP Message Signatures (RFC 9421) under the Agent-DID profile. A client that activates it sends the URI in the A2A-Extensions header.

{
  "uri": "https://agent-did.org/a2a/identity/v1",
  "required": false,
  "params": {
    "did": "did:webvh:{SCID}:example.com:agents:support",
    "keyIds": ["did:webvh:{SCID}:example.com:agents:support#key-1"]
  }
}

The verification rules, the reasons a verifier reports and the Agent Card signature are defined by the A2A Identity Composition Contract and RFC-001.
