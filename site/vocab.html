Agent-DID Vocabulary

Namespace https://agent-did.org/vocab#. The terms are defined for JSON-LD by the context https://agent-did.org/v1. The normative text is RFC-001; this page is a human-readable index of the terms.

Classes

AgentMetadata
The type of the agentMetadata object of an agent's DID document.
AgentMetadataCredential
A W3C Verifiable Credential (Data Model 2.0) in which the agent's controller states agentMetadata members about the agent, presented out of band instead of being published in the DID document (RFC-001 §4.4).

Properties

agentMetadata
Descriptive members of an agent, stated by its controller (RFC-001 §4.2): name, description, version, coreModelHash, systemPromptHash, capabilities, memberOf.
coreModelHash
Optional commitment to the model the agent runs on. An assertion by the controller, not a verified fact (RFC-001 §4.3).
systemPromptHash
Optional commitment to the agent's base prompt. An assertion by the controller, not a verified fact (RFC-001 §4.3).
capabilities
Set of capability labels the controller declares for the agent.
memberOf
Identifier of the fleet or cohort the agent belongs to.
complianceCertifications
References to compliance credentials about the agent.
proofHash
Content address of the evidence behind a compliance certification.
deactivated
Time (xsd:dateTime) at which a verification method was retired by rotation. The method stays in the document so that signatures can be checked at the time they state (RFC-001 §6.2.2).
blockchainAccountId
Account identifier of a verification method in the deferred EVM profile.
