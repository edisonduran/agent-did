# RFC-001 EVM Profile (moved)

The optional EVM deployment profile of RFC-001, its reference `AgentRegistry` contract, the audit automation and the adapters `@agentdid/evm` (npm) and `agent-did-evm` (PyPI) moved to **[edisonduran/agent-did-evm](https://github.com/edisonduran/agent-did-evm)** in `1.0.0-rc.5`, with their git history. The profile document is [`docs/RFC-001-EVM-Profile.md` in that repository](https://github.com/edisonduran/agent-did-evm/blob/main/docs/RFC-001-EVM-Profile.md).

The EVM profile is not part of the core RFC-001 conformance floor. See [ADR-004](ADR-004-EVM-Profile-Satellite.md) for the decision.
